### Remaining BLOCKERs

- **Cartesian jump detection runs after resampling.** Installed Jazzy MoveIt retimes and resamples at 100 ms before returning the path. At the Panda demo’s speed scaling, even a large wrist reconfiguration can be spread into steps below 0.5 rad and dispatched without checking the resulting TCP path. [moveit_client.py:295](/home/anson/workspaces/handeye_autopilot/handeye_autopilot/handeye_autopilot/ros/moveit_client.py:295) · [node.py:878](/home/anson/workspaces/handeye_autopilot/handeye_autopilot/handeye_autopilot/ros/node.py:878)
- **The box check executes a different path from the one it samples.** Panda’s standard controller uses splines for timed points with derivatives. Near a box face, the carried object can cross the boundary between points even when the sampled linear path clears it. The separate `ExecuteTrajectory` dispatch also bypasses MoveGroup’s continuing scene checks, so an obstacle reported during the sequential FK checks can enter the path before execution.
